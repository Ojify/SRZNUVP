# Сервис регистрации заявок на участие в проектах
## Назначение
Приложение представляет собой удобный интерфейс для быстрого поиска интересующих пользователя проектов и регистрации заявок на участие в них.
Приложение решает следующие задачи: 
- автоматизация бумажной работы на регистрацию заявок на участие в проектах.
- облегчение процесса поиска пользователями интересующих их проектов.
- упрощение процесса регистрации заявок на участие в проектах.
## Целевая аудитория
Целевой аудиторией проекта являются активные и творческие люди, готовые и желающие участвовать в различных проектах.
## Предметная область
Предметная область охватывает процессы взаимодействия между инициаторами проектов и потенциальными участниками. Она включает в себя каталогизацию проектов, управление статусами заявок, а также обработку данных о компетенциях пользователей. Система призвана заменить неэффективный документооборот на структурированный цифровой процесс с четкой логикой принятия решений.
## Основные сущности
- Пользователь — физическое лицо, имеющее учетную запись, профиль с контактами и списком навыков.
- Проект — инициатива, созданная организатором, с описанием, сроками, требуемыми ролями и количеством мест.
- Заявка — запрос от пользователя на участие в конкретном проекте, содержащий статус рассмотрения.
- Категория / Теги — справочные данные для классификации проектов для удобного поиска.
- Статус проекта — жизненный цикл проекта.
## Основные функции
- Проверка возможности подачи заявки на участие в проекте.
- Добавление проекта.
- Редактирование проекта.
- Удаление проекта.
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
